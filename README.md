# ExposureDetect

An authorization-first exposure assessment tool for identifying and documenting externally observable security exposure across explicitly scoped assets.

> **Project status:** repository bootstrap is in progress. The complete source baseline has not yet been imported or validated.

## Safety

Only assess assets you own or are explicitly authorized to test. Every scan must operate within an explicit, documented target scope.

## Project principles

- Explicit authorization and scope before scanning.
- Safe defaults and conservative network behavior.
- Evidence-based findings with clear limitations.
- Reproducible output suitable for review and remediation.
- Security controls and tests treated as part of the product, not optional add-ons.
